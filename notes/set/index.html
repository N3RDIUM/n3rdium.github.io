a set is a well-defined unordered collection of unique elements. in order to define a set, given an element, one must be able to tell whether or not it is an element of the set. these elements can be anything, even other sets.

# membership

  • if a set \(A\) includes an element \(1\), we say \(1 \in A\) ("\(1\) belongs to \(A\)")
  • if a set \(A\) does not include an element \(3\), we say \(3 \not\in A\) ("\(3\) does not belong to \(A\))

# representation

usually, sets are denoted by a capital letter. if letters are elements of the set, they are usually lowercase to avoid confusion.

# roster/tabular form

in this representation, the comma-separated elements of the set are enclosed by braces \(\lbrace \rbrace\). for example, \(A = \lbrace 1, 2, a, b, c \rbrace\)

# set-builder form

in this form, we collect all the elements (represented by a variable, say \(x\)) that fulfil a certain condition. for example:

\[ B = \lbrace x : x^2 = 4 \rbrace \]
\[ C = \lbrace x : x \text{ is a vowel in the english alphabet} \rbrace \]

the colon (\(:\)) is read as “such that”. hence, \(B\) in the above example is the “set of all \(x\) such that \(x\) is a square root of \(4\)”. its elements are \(\pm 2\).

in some texts, (\(|\)) is used instead of (\(:\)).

# types

based on the number of elements, sets can be classified as:

  • empty sets: do not have any elements. denoted by (\(\emptyset\)).
  • singleton sets: contain exactly one element.
  • finite sets: have a finite number of elements.
  • infinite sets: have an infinite number of elements.

# commonly used sets

  • \(N\): set of all natural numbers
  • \(Z\): set of all integers
  • \(Q\): set of all rational numbers
  • \(R\): set of all real numbers

adding the suffix (\(^+\)) to any of (\(Z\), \(Q\), or \(R\)) implies that only positive values are included: viz. \(Q^+\) is the set of all positive rational numbers.

# relations between sets

# equality

two sets \(A\) and \(B\) are equal (\(A = B\)) if every element of \(A\) is also an element of \(B\), and every element of \(B\) is also an element of \(A\).

# subset

a set \(B\) is said to be a subset of set \(A\) (written as \(B \subset A\)) if every element of \(B\) is an element of \(A\). \(\emptyset\) is a subset of all sets.

if \(B \subset A\) and \(B \neq A\), \(B\) is a proper subset of \(A\). if \(B \subset A\) but \(B = A\), \(B\) is an improper subset of \(A\), also written as \(B \subseteq A\).

in terms of subsets, the equality can be defined as follows:

\[ A = B \text{ if } A \subseteq B \text{ and } B \subseteq A \]

# superset

set \(A\) is said to be a superset of set \(B\) if \(B\) is a subset of \(A\).

# the universal set

usually denoted by \(U\). it is the set which is the superset of all the sets under study. of course, it is defined based on the context of the study.

# set operations

see venn diagram for visual representations of these operations.

# union

a union of two sets \(A\) and \(B\) is a set that contains all the elements that belong to either \(A\) or \(B\). denoted as \(A \cup B\).

\[ A \cup B = \lbrace x : x \in A \text{ or } x \in B \rbrace \]

properties of the union operation:

  • \(A \cup B = B \cup A\) (commutative law)
  • \((A \cup B) \cup C = A \cup(B \cup C)\) (associative law)
  • \(A \cup U = U\) (law of \(U\))
  • \(A \cup \emptyset = A\) (identity)
  • \(A \cup A = A\) (idempotent law)

# intersection

an intersection of two sets \(A\) and \(B\) is a set that contains the elements that belong to both \(A\) and \(B\). denoted as \(A \cap B\).

\[ A \cap B = \lbrace x : x \in A \text{ and } x \in B \rbrace \]

properties of the union operation:

  • \(A \cap B = B \cap A\) (commutative law)
  • \((A \cap B) \cap C = A \cap (B \cap C)\) (associative law)
  • \(A \cap U = A\) (law of \(U\))
  • \(A \cap \emptyset = \emptyset\) (law of \(\emptyset\))
  • \(A \cap A = A\) (idempotent law)
  • \(A \cap (B \cup C) = (A \cap B) \cup (A \cap C)\) (distributive law)

# difference

the difference of set \(A\) with \(B\) denoted by \(A - B\) is a set that contains all elements of \(A\) that do not belong to \(B\). unlike union and intersection, this operation is non-commutative.

\[ A - B = \lbrace x : x \in A \text{ and } x \not\in B \rbrace \]

# complement

the complement of a set \(A\) is a set represented by \(A’\) (also written as \(A^C\)) (read as “a complement”) such that \(A' = U - A\).

properties of complement sets:

  • \(A \cup A' = U\) and \(A \cap A' = \emptyset\) (complement laws)
  • \((A \cup B)' = A' \cap B'\) and \((A \cap B)' = A' \cup B'\) (DeMorgan’s laws)
  • \((A')' = A\) (double complementation)
  • \(\emptyset' = U\) and \(U' = \emptyset\)
